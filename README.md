# Handwritten Alphabet Recognition Using Deep Learning and CNN

This project recognizes handwritten English alphabets (A–Z) using a CNN model and predicts the alphabet through a Streamlit web application.

## Features
- Handwritten alphabet recognition
- Deep learning based CNN model
- Real-time prediction
- Streamlit web deployment

## Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- OpenCV
- Streamlit

## Files
- app.py
- train_model.py
- requirements.txt
- alphabet_model.h5
